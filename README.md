# Chocolate-Company-Sales-Analysis-using-Power-Bi
Power BI Sales Analysis Dashboard for a chocolate company, providing insights into revenue, costs, profitability, and sales across countries, products, and time periods.
This Power BI dashboard offers a detailed sales performance analysis for a chocolate company. Key features include:

Sales insights by country, product, and time period

Metrics on revenue, cost, and profitability

Interactive visuals to support data-driven decisions
